批量导入外部节点

若设置 N，则节点依 N, N+1, N+2 自动递增分配（跳过已被占用端口）。
导入的 ss/vless/trojan/socks/http 节点统一转换为该出口协议对外提供。
批量导入的节点统一使用此账号密码（对外 socks5/http 认证）。

🌀 多域名解析轮询中转入口 (Load Balance / URL-Test)

每个域名是一个独立的轮询入口，可各自指定参与轮询的分组。例如：域名 A 轮询「家宽」分组，域名 B 轮询「普通」分组。 对外暴露固定 Socks5/HTTP 入口，后端 SingBox 随机/按延迟分发至所选分组节点。

每个域名可独立配置端口 / 认证 / 轮询分组
